# Манай төсөв

Гэр бүлийн сарын орлого, зарлагыг бүртгэж, хаана хэт их зарцуулж байгаагаа харж, ангилал бүрээр төсөв тавьж хянадаг вэб апп. Апп нь браузер дээр ажиллаж, өгөгдлийг тухайн төхөөрөмжийн localStorage-д хадгална. Сервер, нэвтрэлт шаардахгүй.

Дэлгэрэнгүй шаардлагыг [SPEC.md](SPEC.md)-ээс үзнэ үү.

## Яаж ажиллуулах

1. `index.html` файлыг браузерт нээнэ.
   - JavaScript нь ES модуль тул зарим браузер `file://`-аар нээхэд модулийг ачаалахгүй байж болно. Тэр үед төслийн хавтаст локал сервер ажиллуулна:
     ```
     npx serve .
     ```
     дараа нь гарч ирсэн хаягийг (жишээ нь `http://localhost:3000`) браузерт нээнэ.
2. Тест ажиллуулах (Node.js 20+ хэрэгтэй):
   ```
   npm test
   ```

## Feature-үүд

| Дугаар | Feature | Ач холбогдол | Төлөв |
| --- | --- | --- | --- |
| F1 | Гүйлгээ нэмэх | Must | Дууссан |
| F2 | Гүйлгээ засах, устгах | Must | Дууссан |
| F4 | Сарын хураангуй | Must | Хийгдээгүй |
| F9 | Хадгалалт (localStorage) | Must | Дууссан |
| F3 | Ангилал удирдах | Should | Хийгдээгүй |
| F5 | Төсөв тавих, анхааруулга | Should | Хийгдээгүй |
| F7 | Шүүлт, хайлт | Should | Дууссан |
| F6 | График | Could | Хийгдээгүй |
| F8 | Нөөцлөх (JSON татах/оруулах) | Could | Хийгдээгүй |

Төлөв: **Хийгдээгүй** → **Хийгдэж байна** → **Дууссан**

## Файлын бүтэц

```
├── index.html        # Дэлгэцийн бүтэц, табууд
├── css/style.css     # Харагдах байдал
├── js/
│   ├── app.js        # Эхлүүлэх, таб солих
│   ├── storage.js    # localStorage унших/бичих, JSON татах/оруулах (дараа)
│   ├── calc.js       # Тооцоо: сарын нийлбэр, төсвийн хувь (дараа)
│   ├── ui.js         # Дэлгэц зурах (дараа)
│   └── charts.js     # График (дараа)
├── tests/            # node --test тестүүд
├── package.json      # npm test
├── CLAUDE.md         # Claude Code-д өгөх төслийн дүрэм
├── SPEC.md           # Төслийн спек
└── README.md
```

## Хөгжүүлэлтийн үе шат

1. **Суурь** — файлын бүтэц, табууд, storage.js, анхны ангиллууд (F9)
2. **Гүйлгээ** — нэмэх, засах, устгах, жагсаалт, шүүлт (F1, F2, F7)
3. **Хураангуй + график** — calc.js, тестүүд, сар сонгогч (F4, F6)
4. **Төсөв + ангилал** — төсөв таб, анхааруулга, ангилал удирдах (F3, F5)
5. **Нөөц + өнгөлгөө** — JSON татах/оруулах (F8), утасны дэлгэц
6. **Байршуулалт** — GitHub (private) + Netlify автомат шинэчлэлт
